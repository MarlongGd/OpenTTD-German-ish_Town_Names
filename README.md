#  German-ish Town Names / Deutschige Städtenamen
a NewGRF, designed for the OpenTTD simulation game, hoping you will find it funny.

## Description

### English
Thousands of possible names that could be German town names. All nonsense, many of them funny. This NewGRF might allow you to go from Ganz am Anfang to Abseilen auf dem Acker via Bad Turn. At least basic knowledge of the German language helps enjoying this it.

### German
Tausende mögliche Namen, die deutsche Städte bezeichnen könnten. Alle sinnlos, einige davon lustig. Mit Glück kann man so zum Beispiel von Ganz am Anfang über Links Abbiegen nach Bremswegen fahren.

## Build Information
The original build environment is on Linux. However, I expect that for building the NewGRF on a very different system, only the bash script "mkgrf" needs to be adapted.

### Requirements for building

- nmlc (I used version 0.9, located in ~/.local/bin, otherwise you need do change its path in )
- python (I used version 3.14)
- bash (the shell for Unix-like systems; required for mkgrf unly; easy to replace)

### Building the NewGRF

There is no automatic build or publishing process. Just run ./mkgrf. mknml.py creates the nml source file only.
