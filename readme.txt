German-ish Town Names / Deutschige Städtenamen
==============================================

Tausende mögliche Namen, die deutsche Städte bezeichnen könnten.
Alle hoffentlich sinnlos, viele davon lustig. Mit Glück kann man
so zum Beispiel von Ganz am Anfang über Links Abbiegen nach
Bremswegen fahren.


Description - English
---------------------

Thousands of possible names that could be German town names.
Hopefully all nonsense and many of them funny. This NewGRF might
allow you to go from Ganz am Anfang to Abseilen auf dem Acker
via Bad Turn.
At least some basic understanding of German helps enjoying it.
